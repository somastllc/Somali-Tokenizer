# Changelog

All notable changes to Somali-Tokenizer are documented here.
Format based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versioning
follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Two version lines are tracked separately and must not be conflated:

- **Software version**: the Rust library and CLI. Semantic versioning applies. That is
  what the headings below refer to.
- **Tokenizer artifact version**: the identity of a released vocabulary and merge table
  (`somali-bpe-v2` and successors). Defined in
  [docs/REPRODUCIBILITY.md](docs/REPRODUCIBILITY.md). An artifact change is recorded in an
  `### Tokenizer artifacts` section, never by renumbering a software release.

## [Unreleased]

No release has been published yet. The Rust implementation, CLI, and Python package below

### Added

- **Rust library** (`crates/somali-tokenizer`): loads and validates `tokenizer.json`
  artifacts against the v2 contract, then encodes and decodes. Built on the Hugging Face
  `tokenizers` crate, pinned to 0.21.4. The v2 release is bundled for offline use;
  `from_pretrained` (feature `http`) loads from the Hugging Face Hub.
- **Command-line tool** with `encode`, `decode`, `inspect`, `train`, `benchmark`, and
  `stats` subcommands. `train` streams a corpus release, holds out the evaluation split,
  supports vocabulary sweeps by merge truncation, writes a run record, and refuses to write
  into `artifacts/releases/`.
- **Python package** `somali-tokenizer` (`bindings/python`), built with PyO3 and maturin as
  an abi3 wheel for Python 3.9 and later.
- **Parity suite** against the Python reference: identical token ids on 225 texts,
  identical vocabulary and merges from training, matching benchmark and corpus statistics,
  and the same holdout split. Fixtures in `tests/fixtures/`, generated by
  `python-reference/make_parity_fixture.py`.
- **Python reference** imported from Somali NLP Corpus with its Git history, under
  `python-reference/`.
- **CI**: formatting, Clippy with warnings denied, Rust tests, an MSRV build, the Python
  reference tests, and wheel builds with tests on Linux, macOS, and Windows.

### Tokenizer artifacts

- `artifacts/releases/v1/` and `artifacts/releases/v2/` hold the existing v1 and v2
  artifacts, unchanged, with `SHA256SUMS`. The v2 `tokenizer.json` is byte-identical to
  [`somast/somali-bpe-v2`](https://huggingface.co/somast/somali-bpe-v2).

### Notes

- The full-corpus benchmark figures in the documentation were measured by the Python
  reference implementation, which now lives in `python-reference/`. The Rust
  implementation reproduces them on the fixture corpus; it has not yet been re-run on a
  full corpus release.
